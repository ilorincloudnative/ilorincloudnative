# Cloud Native Ilorin

Welcome to the Cloud Native Ilorin GitHub 👋🏾

Cloud Native Ilorin (CNI) is a community for people interested in learning, building, and growing in cloud-native technologies and open source.

This space is where we'll share learning resources, hands-on projects, experiments, and community contributions.

## What you'll find here

* ☁️ Cloud-native learning resources
* 🛠️ Hands-on projects and labs
* 🌱 Beginner-friendly open-source contributions
* 📚 Guides and learning materials
* 🤝 Community projects

## Getting Started

You don't need to be an expert to contribute.

Whether you're just learning Git and GitHub or already working with cloud-native technologies, there's room for you here.

Start by exploring our repositories, try out a project, and when you're ready, make your first contribution.

## Our Goal

We want to make it easier for people in Ilorin and beyond to learn cloud-native technologies, get hands-on experience, and take their first steps into open source.

**Learn. Build. Contribute.**
